# 🐸 Toadsage NixOS Configurations
Welcome to my NixOS configuration repository, where I blend the wisdom of the Toad Sage with the power of declarative Linux. This setup focuses on providing a lightweight, customizable, and visually pleasing desktop environment using [Hyprland](https://github.com/hyprwm/Hyprland).

---

## ✨ Features
- **Hyprland**: A modern Wayland compositor for dynamic and tiling window management.
- **Alacritty**: A GPU-accelerated terminal emulator, fast and simple.
- **Rofi**: A customizable application launcher and menu.
- **Modular NixOS**: Easy-to-use and reusable configurations for different setups.
